### 🚀 Projects

- **[LLM Relay (High-Performance AI Gateway)](https://github.com/Divyanshu-yadav-18/llm_relay)** `[Go, Redis, PostgreSQL, Docker, Grafana]`
  > A multi-provider LLM gateway delivering a unified OpenAI-compatible REST API. Features a high-speed semantic response cache using an HNSW index (<15ms latency), token-bucket rate limiting via Redis Lua, and full observability using Prometheus and Grafana.

- **[Distributed Job Queue](https://github.com/Divyanshu-yadav-18/Job-Quese)** `[Go, Redis, Docker]`
  > A fault-tolerant job queue system with a DAG dependency engine, heartbeat-based health checks, worker pool architecture, and token-bucket rate limiting. Containerized microservices using multi-stage Docker builds.

- **[StreamSync (Real-Time Video Synchronization)](https://github.com/Divyanshu-yadav-18/StreamSync)** `[TypeScript, Socket.io, FFmpeg, Docker, Nginx]`
  > A real-time synchronized video-watching platform using WebSockets (sub-100ms drift). Integrates an FFmpeg processing pipeline for HLS adaptive bitrate chunked delivery and handles distributed race conditions efficiently.
